## Skills

- **[pr-understanding](./skills/pr-understanding/SKILL.md)** — Understand a PR by
  building a falsifiable map instead of a vague summary. Opens with what changed, why
  and how, then a reading order, a Mermaid diagram of the changed flow, the blast
  radius, and a "verify these" checklist — rendered to an HTML page. Say
  *"understand PR #123"* or *"what does this change do"*.
